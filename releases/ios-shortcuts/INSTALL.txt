iOS Toolkit — install (iPhone / Safari)

Apple rejects shortcuts://import-shortcut for non-iCloud URLs
("shortcut URL is invalid"). Download the file instead:

1) Open this in Safari:
   https://h.uguu.se/KGDDYOGh.shortcut

2) Open the downloaded iOS-Toolkit.shortcut → Add Shortcut

3) Settings → Shortcuts → Allow Untrusted Shortcuts (if asked)

4) Add to Home Screen from the shortcut share sheet
