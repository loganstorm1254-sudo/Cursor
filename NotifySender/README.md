# Notify Sender

Sends notifications to Notify Receiver over **Bluetooth**.

No Wi‑Fi, data, hotspot, or IPs.

## Use

1. On the other phone: Notify Receiver → **Start**.
2. Here: turn **Bluetooth ON** → tap **Link receiver** once.
3. Enter title + message → **Send notification**.

After linking once, you can send anytime (while Receiver is listening and phones are nearby).

## Build

```bash
./gradlew assembleDebug
```
