# Ready-to-install APKs (Samsung / any Android 8+)

| File | Install on |
|------|------------|
| [`NotifyReceiver.apk`](NotifyReceiver.apk) | Phone that should **get** notifications |
| [`NotifySender.apk`](NotifySender.apk) | Phone that should **send** notifications |

## Install on Samsung

1. Download both APKs to each phone (or one each).
2. Open **My Files** → Downloads → tap the APK.
3. If asked, allow **Install unknown apps** for My Files / Chrome / whatever you used.
4. Tap **Install**.

## Use

1. Same Wi‑Fi on both phones.
2. On the receiver phone: open **Notify Receiver** → **Start** → allow notifications.
3. On the sender phone: open **Notify Sender** → **Find receivers** → pick the other phone → send.

If Find receivers fails, type the IP shown in Notify Receiver and tap **Use this IP**.
