# Notify Receiver

Listens over **Bluetooth** and shows system notifications from Notify Sender.

No Wi‑Fi, data, hotspot, or IPs.

## Use

1. Install on the phone that should get alerts.
2. Turn **Bluetooth ON**.
3. Open the app → allow Bluetooth + notifications → tap **Start**.
4. Keep phones near each other (about room distance).

## Build

```bash
./gradlew assembleDebug
```
