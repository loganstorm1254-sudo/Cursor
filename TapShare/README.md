# TapShare

Share a photo by tapping two phones together (or pressing Share). Uses **Google Nearby Connections** (Bluetooth + Wi‑Fi) so it actually finds the other phone on Samsung.

## Install

1. Install `releases/TapShare.apk` on **both** phones (uninstall any older TapShare first).
2. Open TapShare → allow **all** prompts: photos, nearby devices, location, Wi‑Fi nearby, notifications.
3. Turn **Bluetooth ON** and **Location ON** on both phones.
4. Tap **Allow background**.
5. Keep TapShare open (notification “looking for nearby…”).

## Share

1. Phone A: Open Gallery → pick a photo.
2. Phone B: leave TapShare running (home screen is fine).
3. Hold phones close → tap tops **or** press **Share over Bluetooth**.
4. Ripple animation → photo opens full screen on phone B.
