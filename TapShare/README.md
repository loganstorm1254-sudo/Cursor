# TapShare

Open a photo in **Samsung Gallery**, then **tap the tops** of two phones together. No Share button — it only shares on a real tap.

## Setup (both phones)

1. Install `releases/TapShare.apk` (uninstall older TapShare first).
2. Open TapShare → allow photos, nearby devices, location, notifications.
3. Tap **Enable for Samsung Gallery** → turn **TapShare** ON in Accessibility.
4. Bluetooth ON, Location ON, **Allow background**.

## Use

1. Leave TapShare running on both phones (persistent notification).
2. Phone A: open a photo in **Samsung Gallery**.
3. Knock the **tops** of both phones together.
4. Ripple animation → photo opens on phone B.

It will **not** share if the phones aren’t tapped (both phones must register a tap).
